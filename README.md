# Алгебра 8 — тренажёр «Сумма и разность дробей»

Статический учебный мини-сайт по §§ 3–4 (страницы 19–30 предоставленного материала):
- сложение и вычитание рациональных дробей с одинаковыми знаменателями;
- противоположные знаменатели;
- сложение и вычитание дробей с разными знаменателями;
- поиск общего знаменателя и дополнительных множителей;
- разложение знаменателей на множители;
- преобразование суммы/разности целого выражения и дроби;
- типичные ошибки со знаками и сокращением.

## Как запустить локально
Откройте файл `index.html` двойным нажатием или через Safari/Chrome. Сервер не нужен.

## Как загрузить на GitHub
1. Создайте новый репозиторий.
2. Загрузите `index.html`, `styles.css`, `script.js`, `questions.js`, `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch → main → /(root)**.
5. Сохраните настройки.

## Структура
- `index.html` — интерфейс и учебный конспект.
- `styles.css` — адаптивный дизайн для iPad и компьютера.
- `script.js` — интерактивы, тренировка, опрос, статистика.
- `questions.js` — банк из 72 заданий.
- `README.md` — инструкция.

## Режимы
- **Выучить** — пошаговые правила и примеры.
- **Интерактив** — 5 моделей: первый шаг, дополнительные множители, противоположные знаменатели, поиск ошибки, порядок алгоритма.
- **Потренироваться** — задания по одному с немедленным объяснением.
- **Опрос** — 12 сбалансированных заданий без подсказок, результат в конце.
- **Статистика** — локальная статистика по темам и навыкам через `localStorage`.

Сайт не использует React, Vue, npm, сервер, базу данных или внешние CDN.
